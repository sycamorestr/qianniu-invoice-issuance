# 按店铺配置税率

技能根目录的 `tax-rates.json` 保存本机税率规则，迁移时随技能目录一起复制。首次设置可复制 `assets/tax-rates.example.json`，把例外店铺名替换为清单中的完整 `store` 名称：

```json
{
  "schema_version": 1,
  "default": {"source": "fixed", "rate": "0.1"},
  "stores": {
    "按票聚税率的店铺全名": {"source": "piaoju"},
    "另一家自定义店铺": {"source": "fixed", "rate": "0.03"}
  }
}
```

`stores` 按完整店铺显示名精确匹配；没有单独条目的店铺使用 `default`，以后新增店铺也遵循此默认值。这里填写 `shops.json` 的 `store` 或单店参数 `--store`，不填写登录账号、店铺 id 或简称；重命名店铺时同步修改对应条目。

- `source="piaoju"`：从票聚接口税率或明确百分比/零税率分类取值，保留原来的税率缺失和冲突检查。
- `source="fixed"`：必须提供 `rate`，取 0 到 1 的小数；`"0.1"` 表示 10%，`"0.01"` 表示 1%，`"0"` 表示零税率。不要填写 `10` 或 `10%`。

固定税率以配置为准，覆盖票聚及通用模板正商品、折扣、价外费用行的税率；不会因票聚税率缺失、分类税率不同或原件税率不同而暂缓。其他商品字段仍需票聚核验，缺少单位、税收编码、名称、不开票或匹配不唯一仍整票暂缓。原始资料保留，不改写采集证据。含税金额、折扣和数量继续取通用模板；配置不对金额另乘税率，也不增加单独税额列。

最终“2-发票明细信息”的税率写为小数文本，包括固定零税率的文本 `0`。计划记录每行实际税率及 `tax_rate_source`：固定规则为 `store_fixed`，票聚规则为原接口/分类来源。`invoice_input.json`、计划和 `run.json` 保存本次有效 `tax_rate_policy`，独立校验再按此规则核对输出。

单店、多店和本地生成入口均支持 `--tax-rate-config <文件>` 覆盖默认位置。未显式指定且技能根目录没有配置时，保持兼容行为：所有店铺使用票聚。指定的文件不存在、JSON 损坏、规则缺失、重复键或税率越界必须在执行前报错，不能回退成其他税率。

新单店任务开始时冻结有效规则；新批次在开始时一次读取配置，为所有选中店铺冻结规则，包括尚未执行的店铺。恢复默认沿用保存值，不受随后修改配置影响；显式传入不同规则会拒绝恢复。旧作业没有该字段时按原票聚规则恢复。修改配置用于下一次新任务；需要把新规则应用于已有采集资料时，创建新的离线重放作业，不覆盖原文件、不自动发送重放结果。

真实 `tax-rates.json` 由 Git 忽略，公开仓库只提供无真实店铺信息的示例。同步代码时保留本机已有配置，不以示例覆盖；它与企微 `notifications.json` 分开管理。
